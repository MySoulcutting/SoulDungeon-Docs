# 路线图

## 当前版本 v0.2.0

已完成的核心功能：

- [x] 副本基础配置（`option.yml`）
- [x] 实例模式（`INSTANCE`）
- [x] 地图导入（`/sd import`）
- [x] 怪物组系统（`monster.yml`）
- [x] 原版实体支持（`VANILLA`）
- [x] MythicMobs 支持（`MYTHIC`）
- [x] 脚本动作引擎（10+ 内置动作）
- [x] 占位符系统
- [x] 实例池预热
- [x] 调试命令（`/sd mobs`、`/sd group`、`/sd bench`）
- [x] 主配置（`config.yml`）

## v0.3.0 — 扩展玩法

计划功能：

- [ ] 障碍物系统（机关门、封印墙）
- [ ] 区域系统（进入检测、范围限制）
- [ ] 交互系统（点击方块、进入区域触发脚本）
- [ ] 更多脚本动作
- [ ] 配置诊断命令（`/sd doctor`）

## v0.4.0 — 编辑器

计划功能：
